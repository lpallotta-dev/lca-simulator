Study framework

ISO 14040/14044 framework · SimaPro 10.5 · Ecoinvent 3.12 · ReCiPe 2016, Hierarchist perspective.

System boundary

Cradle-to-gate. Intermediate transportation, product use and end-of-life are excluded.

Comparison basis

One finished punch with the specified geometry. Batch totals are divided by N for unit results.

Data sources

SolidWorks CAM, WAAM measurements, CENTIMFE data and simulations, literature and background datasets.
